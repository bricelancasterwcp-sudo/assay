# assay v1.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship assay 0.6.0 (profile schema v5): sequential testing for codec verdicts, `assay diff` drift detection, and a long-output integrity probe.

**Architecture:** Three additions to an existing stdlib-only probe library. A new `stats.py` extracts the Wilson/ladder arithmetic both `codecs.py` and `profile.py` need (breaking a would-be circular import); a new `diff.py` compares two profile payload dicts; a new `long_output.py` adds degeneracy metrics and a probe. `run.py` orchestrates, `cli.py` exposes, `report.py` renders.

**Tech Stack:** Python stdlib only (the repo's hard rule — no new dependencies). pytest. Fakes in `tests/fakes.py` (no GPU, no network in tests).

**Spec:** `docs/superpowers/specs/2026-08-14-assay-v1.5-design.md` — read it first; the plan argues from it. Note both dated amendment footnotes (ladder-agreement stopping; healthy-anchor genre demotion).

```python
# src/assay/stats.py  (leaf module: imports nothing from assay)
READY_THRESHOLD = 0.9
RISKY_THRESHOLD = 0.6
LOOK_SCHEDULE = (5, 10, 20, 35)

def wilson95(passes: int, n: int) -> tuple[float, float]: ...
    # MOVE verbatim from profile.py (docstring included). n=0 -> (0.0, 1.0).

def ladder(rate: float | None, *, ready_blocked: bool = False) -> str: ...
    # MOVE verbatim from profile._ladder (returns "unmeasured"/"ready"/"risky"/"unusable")

def decided(passes: int, n: int) -> bool:
    """Sequential stop test (spec §1, amended form): the Wilson-95
    interval endpoints ladder to the SAME rung. Exactly the negation
    of the provisional condition."""
    lo, hi = wilson95(passes, n)
    return ladder(lo) == ladder(hi)
```

```python
# src/assay/diff.py — operates on RAW payload dicts (json.loads of a
# profile file), NOT Profile objects: old-schema payloads lack keys
# that Profile.from_json indexes, and diff must read v1..v5 alike.
from dataclasses import dataclass

@dataclass(frozen=True)
class Change:
    family: str      # "ceiling" | "ceiling_shapes" | "verdict" | "codec" | "speed"
    cell: str        # e.g. "max_verified", "shape:4096", "patch_editing",
                     #      "whole_file.small.lands_applies", "decode_tps"
    direction: str   # "regression" | "improvement" | "neutral"
    old: object
    new: object
    basis: str       # "rung-change" | "flip" | "disjoint-intervals" |
                     # "beyond-2se" | "threshold-20pct-assumed"

@dataclass(frozen=True)
class DiffResult:
    comparable: bool
    identity_notes: tuple[str, ...]   # mismatches (fatal) or warnings
    changes: tuple[Change, ...]
    within_noise: tuple[str, ...]     # cells checked and clean, named
    dropped: tuple[str, ...]          # cells present on one side only

def identity_gate(old: dict, new: dict) -> tuple[bool, tuple[str, ...]]: ...
def diff_profiles(old: dict, new: dict) -> DiffResult: ...
def render_diff(result: DiffResult) -> str: ...
```

**Identity gate (spec §2, "blob digest" realized as the fields profiles actually carry — record this in the module docstring):**

| field | source | rule |
|---|---|---|
| model name | `model.name` | must be equal (fatal) |
| quant | `model.quant` | equal when both non-None (fatal); one None → warning note |
| weights_bytes | `model.weights_bytes` | equal when both non-None (fatal); one None → warning note |
| tier | `provenance.tier` | must be equal, both-None ok (fatal) |
| emulated | `provenance.emulated` | must be equal (fatal) |

**Comparison rules (verbatim — the guess-wrong parts):**

- Ceiling: `ceiling.max_verified` differs → Change, basis `rung-change`, direction regression when it shrank. Same for `failure_mode` (basis `flip`; a move from an honest mode into `{"silent_truncation", "missing_stats"}` is a regression; the reverse is an improvement; honest→honest is neutral).
- Shapes: match entries by their `shape` value; compare `max_verified` and `failure_mode` per matched shape (cell `f"shape:{shape}"`); unmatched shapes → `dropped`.
- Verdicts: for every verdict name in either profile, compare `verdict` strings. Ladder order for direction: ready > risky > unusable; `unmeasured` on either side → that verdict goes to `dropped`, never scored. `provisional` flips alone are `neutral` Changes (basis `flip`). Basis for ladder moves: `flip`.
- Codec cells: for every codec × grade × lens (`lands`, `lands_applies`) present with n > 0 on BOTH sides: compute `wilson95(round(rate*n), n)` per side; flag a Change ONLY when the intervals are disjoint (basis `disjoint-intervals`; direction by which side is higher); overlapping → the cell name goes in `within_noise`. n == 0 or missing on either side → `dropped`.
- Speed (`decode_tps`, `prefill_tps` separately): when both sides carry ≥2 samples, use Welch 2-SE: `se = sqrt(var_old/n_old + var_new/n_new)` with n-1 sample variance; flag when `abs(mean_new - mean_old) > 2*se` (basis `beyond-2se`). Otherwise (either side has <2 samples or a pre-v5 profile has none): flag when relative change exceeds 20%, basis `threshold-20pct-assumed`, and `render_diff` prints that basis string verbatim so the assumption is visible. Direction: slower is regression.
- `render_diff`: one line per Change (`family.cell: old -> new (direction, basis)`), then `within noise: ...`, then `dropped: ...`, matching `render_table`'s plain-text style. Empty changes → first line `no drift beyond noise`.
